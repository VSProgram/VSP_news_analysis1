# Financial News Analysis with LLM

Pet-project по анализу финансовых новостей с использованием больших языковых моделей (LLM).

Цель проекта - автоматическое выявление значимых событий в новостях и извлечение экономических сущностей.

## Архитектура проекта

Реализован пайплайн анализа новостей, включающий:

1. Предобработку текста
2. Бинарную классификацию новости:
   - событие
   - не событие
3. Анализ содержания новости
4. Извлечение экономических сущностей

## Модель

Используется локально запущенная LLM:

**T-lite-it-2.1-Q4_K_M**

Запуск осуществляется через:

**llama.cpp**

## Результаты

- accuracy: **0.75**
- тестовая выборка: **290 новостей**

## Технологии

- Python
- LLM
- llama.cpp
- Prompt Engineering
- NLP

## Назначение

Проект исследует возможность использования LLM для автоматического анализа новостного потока и выявления экономических событий.
