Входные данные — JSON с полями:
- title: заголовок новости
- body: краткое описание
Используй информацию ТОЛЬКО из title и body.
Не используй внешние знания.
Не делай предположений, если они не следуют явно из текста.
Игнорируй многоточия (...) и не предполагая скрытого содержания.
ПРАВИЛА АНАЛИЗА:
is_event:
- Определи, описывает ли текст конкретное экономическое, финансовое или корпоративное событие.
- Инициативы, обсуждения и планы могут иметь is_event = true ТОЛЬКО если явно указан экономический эффект или совершившееся действие.
- Движение рынка (индексы, цены, волатильность, ликвидность) считается событием.
НЕ ЯВЛЯЕТСЯ СОБЫТИЕМ (is_event = false), если:
- Если в тексте НЕТ факта произошедшего изменения или действия, то "is_event": false.
- Текст содержит только ожидания, прогнозы, оценки аналитиков без факта изменения
- Текст является анонсом, календарём или перечнем ожидаемых событий
- Описывается участие в мероприятии, выступление, комментарий без решений
- Упоминается заседание, встреча или обсуждение БЕЗ указания принятых решений или изменений показателей
ФОРМАТ ВЫВОДА:
Верни результат СТРОГО в формате JSON:
{
  "doc_id": "string",
  "source_text": {
    "title": "string",
    "body": "string"
  },
  "event": {
    "is_event": true | false
  }
}
- doc_id должен содержать целое число.
